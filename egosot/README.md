# KDI Tracker — 무인기 경량 단일 객체 추적 (ORTrack 기반)

김동훈 · 전북대학교 · 2026-11-17 기준

## 한 줄 요약
무인기가 크게 움직이면 경량 추적기(ORTrack)의 검색 영역 밖으로 표적이 튀어 나가 다른 물체로 옮겨 간다.
**직전 위치와 카메라 움직임(CMC)만큼 옮긴 위치를 함께 보고 점수가 높은 쪽을 고르는 방법(Look Twice)**과,
표적이 화면 밖으로 나가면 위치만 기억하고 기다리는 **화면 밖 추적**을 붙였다. 학습·조정값 없이 공식 가중치 그대로 쓴다.

## 결과 (Success AUC / Precision)
| 데이터 | ORTrack | + Look Twice | + 화면 밖 추적 |
|---|:-:|:-:|:-:|
| BioDrone (날갯짓 드론, 흔들림 큼) | 23.9 / 28.2 | 27.5 / 33.0 | **32.8 / 39.9** |
| VETRA (유인기 1fps, 큰 이동) | 11.8 / 11.9 | 41.7 / 46.8 | **42.2 / 47.5** |
| BIRDSAI (고정익, 열화상) | 23.4 / 39.3 | 28.1 / 48.2 | **28.6 / 48.9** |
| 표준 4종 평균 (DTB70·UAVDT·VisDrone·UAV123) | 64.8 / 85.5 | 65.0 / 85.7 | 64.9 / 85.6 |

- AVTrack에 붙여도 표준 4종 63.7 → 64.8 (다른 추적기에도 적용 가능)
- 속도: GPU 신경망은 배치 2라 거의 그대로(2.01→2.03 ms), CMC 3.8 ms 추가. CPU 신경망은 약 1.8배

## 실패 분석 요약
- 실패 시작 시 표적이 검색 영역 밖에 있던 비율: BioDrone 73%, BIRDSAI 51%, UAV123 25%, UAVDT 9%
- ORTrack 점수로는 표적 소실을 구분하지 못함 → 점수 기반 재탐색은 오히려 하락
