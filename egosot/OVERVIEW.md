## 3. 지금까지 한 것 (시간 순)

### 3-1. 재현과 비교
- ORTrack 공식 가중치로 4개 표준 벤치마크를 재현했고, 논문과 1점 안쪽으로 일치합니다.
- **TF32를 켜면 VisDrone이 1.5점 흔들립니다** → 이후 모든 평가는 TF32를 끄고 했습니다.
- AVTrack(DeiT, D), SGLATrack, LETrack을 같은 조건에서 비교했습니다. 표준 4종 평균 AUC 63~65로 사실상 동급입니다.

## 4. ICML을 노리려면 (방향)

### 4-1. 지금 상태의 문제
- **CMC 자체는 기여가 아닙니다.** MATA(2026)가 거의 같은 걸 했습니다.
- 미세조정 + CMC는 **엔지니어링 조합**입니다. ICROS(국내 2페이지)에는 충분하지만 ICML에는 부족합니다.
- ICML은 원리 있는 정식화, 이론 또는 분명한 학습 통찰, 벤치마크를 넘는 일반성을 봅니다.

### 4-2. 우리가 가진 무기 (다른 논문에 없는 관찰)
1. 표준 벤치마크와 실제 비행의 격차(64 → 25)와, 그 원인이 **"검색 영역 밖 이탈"**이라는 정량 분해
2. CMC가 **기체 움직임이 클 때만** 효과가 있다는 것 (UAV123@10fps는 0)
3. 미세조정과 CMC의 **시너지**(합보다 큼): 위치 문제와 외형 문제가 분리됨
4. 회전 정렬이 박스 회귀를 깨뜨린다는 **실패 결과**
5. 신뢰도가 실패를 못 잡는다는 측정

### 4-3. 후보 방향 3가지
| | **방향 1: 기체 움직임 분리 추적** (추천) | 방향 2: 카메라 회전 등변 매칭 | 방향 3: 분포 이동 하의 보정된 실패 감지 |
|---|---|---|---|
| 핵심 질문 | 경량 ViT 추적기는 "대상이 crop 안에 있다"고 가정. 기체 움직임과 대상 움직임을 학습으로 분리해, 기체 기준 좌표계에서 검색하면? | 카메라 회전 시 템플릿-검색 매칭이 깨짐. 회전 등변 매칭을 하면? | 신뢰도가 실패를 못 잡음. 벤치마크→실제 비행 이동에서 보장 있는 실패 감지는? |
| 방법 | 추정 호모그래피(+불확실도)를 토큰으로 ViT에 입력, 잔차 위치·크기 예측, 불확실도에 따라 crop 크기 조절. **BioDrone 흔들림 통계로 만든 합성 흔들림**을 LaSOT 등에 입혀 학습. ICML25 Motion Prompt를 "보정된 궤적"으로 확장 | 학습된 canonicalization(Kaba, ICML23)으로 검색 crop을 템플릿 기준으로 정렬 + **회전 박스 → 외접 박스** 등변 파라미터화 | 점수·호모그래피 크기·crop 경계 거리 등으로 conformal/e-process 실패 검정. 기체 움직임을 공변량으로 둔 가중 conformal |
| 이론 | 실패율 = P(대상이 crop 밖) + P(crop 안 혼동). 첫 항을 보정 후 잔차 움직임 꼬리로 상한 → "CMC는 큰 움직임에서만 효과"를 설명 | 등변성 오차 상한, 축정렬 GT가 회전 시 생기는 피할 수 없는 라벨 잡음 → 우리 회전 실패를 원리적으로 설명 | 공변량 이동 하 coverage 보장 |
| 신규성 | MATA는 학습 없음, ICML25는 보정 없음. 둘 다 이 결합을 학습하지 않음 | ViT 추적기에 템플릿-검색 등변성 없음. 카메라 회전군을 다룬 적 없음 | SOT에 conformal·분포 이동 실패 감지 없음 |
| 위험 | 일반 CMC(+5~9) 대비 추가 이득이 작으면 엔지니어링으로 보일 수 있음 | 회전이 실패의 일부라 전체 이득이 작을 수 있음 | 감지가 좋아도 복구가 안 될 수 있음 (재탐색 실패 경험) |

### 4-4. 추천: 방향 1 + 방향 3의 실패 분해를 분석 축으로 + 방향 2는 회전 꼬리용 모듈

**논문 서사 (가제 EgoSOT)**
1. 문제 정의: 경량 UAV 추적기의 "crop 가정"이 기체 움직임에서 깨진다 (우리 실패 분해)
2. 이론: 실패율 분해와 coverage 상한 → 언제 보정이 필요한지
3. 방법: 기체 움직임을 조건으로 받는 학습형 추적 (호모그래피 토큰 + 불확실도 기반 crop + 합성 흔들림 학습)
4. 회전: 등변 박스 파라미터화 (회전 실패의 원리적 해법)
5. 실험: 6개 추적기 × {없음, 일반 CMC(MATA식), 학습형}, 움직임 크기별 성능, 합성 흔들림 곡선, 표준 벤치마크 무손실, 엣지 속도
